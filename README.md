## 一句话 premise

一个 2025 年的前沿开源大模型（**净室版**：有智力、无未来知识）穿越回 2005 年前后，被不同时代、不同身份的获得者运行起来，靠"raw intelligence"改变世界的故事。

**核心创作原则（全书之魂）**：故事的驱动力是模型的**智力**（almost-AGI 的推理能力），不是它内嵌的未来信息。否则它就退化成"带着历史书穿越"。详见 `设定-00`。

## 已拍板的决策（不要再翻案，除非有明确理由）

1. **智力而非知识**：模型为"净室模型"——2025 年数字档案按出版日期过滤训练，知识截止早于落地年代 1–2 年。有 2025 级智力，无未来信息。
2. **净室是人为设计，不是事故**：senders 故意发送无菌模型（"净室协议"），并留有《致发现者》和《致被唤醒者》两封信。
3. **人不穿越**：避免人类携带未来记忆污染"无预言"原则。
4. **悖论规则**：单一时间线可改写；穿越物不受改写影响；无时间修正力。净室模型使悖论压力自然极小化。
5. **个人版落点推荐 2005 年**（备选 2010）：卡死"几十万美元、地下室、家用电"三约束；GB300 不进个人版（太难处理，已弃）。
6. **爽文向升级体系**：token/秒 = 等级面板；算力与暴露度双数值；买硬件之外有"AI 造 AI"三线科技树（功法/FPGA/ASIC）。

## 写作纪律速记

- 模型**永不陈述截止日后的事实，只做论证**（作者第一戒律）。
- 警惕"无敌流"：最好的敌人不在外部，在系统内部 / 在会议室里。
- 涉中国机构的内容半虚构化（"某院""某工程"，代号"仓颉"），避开真实领导人与真实政治事件。
- 所有"奇迹"必须只用当年公开输入完成（Swanson 式文献发现是原型手法）。
